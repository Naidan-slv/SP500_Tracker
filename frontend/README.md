# Frontend (React + Vite)

Lightweight frontend for the Stock Intelligence API.

## Stack
- React + TypeScript
- Vite
- React Router
- Recharts

## Setup
```bash
cd frontend
npm install
cp .env.example .env
```

## Run
```bash
npm run dev
```
Open `http://localhost:5173`.

## Build
```bash
npm run build
npm run preview
```

## API Base URL
Set `VITE_API_BASE_URL` in `frontend/.env`.

Default:
```
https://sp500-tracker.onrender.com
```
